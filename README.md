# Sentinel

บอทเทรด InnovestX แบบ Price Action 2 ชั่วโมง (ชม.ที่ 3 ใช้แค่ห้ามซื้อ)

## เฝ้าหลายเหรียญ (v7)

ไม่ต้องแก้โค้ดเอง — เพิ่มเหรียญจากหน้าเว็บของบอทได้เลย

1. เปิดหน้าแดชบอร์ดบอท
2. ช่อง **เหรียญที่ให้บอทเฝ้า** พิมพ์คู่เหรียญ เช่น `ETHTHB` แล้วกด **เพิ่มเหรียญ**
3. บอทดูทุกเหรียญในรายการด้วยเกณฑ์ **ขึ้นแล้วย่อ**
4. เข้าซื้อตัวที่ย่อในขาขึ้น เมื่อยังมีช่องว่าง
5. ขายไม้เก่าแล้ว จะไปมองหาเหรียญถัดไปที่คุณเพิ่มไว้ทันที

### เกณฑ์เข้าซื้อ

ไม่ไล่ซื้อตอนเหรียญยังพุ่ง ซื้อเมื่อครบทุกข้อ:

- ชม.ก่อนหน้าขึ้นอย่างน้อย **0.7%** (ขาขึ้นมาแล้ว)
- ชม.ล่าสุด**ย่อ** ระหว่าง **0.3% ถึง 1.8%** (ย่อน้อยไป = ยังอยู่หัว, ย่อลึกไป = เทรนด์พัง)
- หลังย่อแล้ว สุทธิ 2 ชม. ยังบวกอย่างน้อย **+0.4%**
- ถ้าราคา 15 นาทีล่าสุดยังลงต่อ จะรอปุ่มก่อน
- ถ้ามีข้อมูล 3 ชม. และชม.3 ลงแรงกว่า **−1.5%** จะห้ามซื้อ
- สเปรด bid/offer ไม่กว้างเกิน **0.53%** — ซื้อเทียบราคา offer, ขายเทียบราคา bid

หน้าเว็บจะขึ้น **ขาขึ้น รอย่อ** ตอนเหรียญยังพุ่ง และ **ย่อแล้ว พร้อมซื้อ** เมื่อเข้าจังหวะ

### เกณฑ์ขาย

- **Stop Loss** — ราคาไม่ขึ้น แล้วร่วงจากต้นทุนเกิน % ที่ตั้ง (ค่าเริ่มต้น 3%) จึงขาย
- **สัญญาณกลับตัว** — ถ้าราคาพลิกลงต่อเนื่อง ทั้งที่ยังเหนือจุดคุ้มทุน จะขายล็อกกำไรทันที **ไม่ต้องรอให้ trailing arm** (กันเคสขึ้นไม่ถึง 1.4% แล้วไหลยาวไปโดน stop) หลังขายแบบนี้จะ**คูลดาวน์ 20 นาที**ก่อนซื้อเหรียญนั้นคืน (ปลดเองอัตโนมัติ ไม่ต้องกดจากหน้าเว็บ)
- **Trailing Stop** — ใช้ล็อกกำไรเมื่อราคาเคยขึ้นพอแล้ว (สูงกว่าต้นทุนอย่างน้อยค่าธรรมเนียม + % trailing) แล้วค่อยย่อจากยอดเกิน % ที่ตั้ง
- ขึ้นแค่ติ๊กแล้วย่อนิดหน่อย **จะไม่ขาย** เพราะยังไม่คุ้มค่าธรรมเนียม ทิ้งให้ Stop Loss ดูแล
- ขายเทียบราคา bid

### ตั้งค่านิดเดียวให้ถือหลายเหรียญได้จริง

- **ถือได้พร้อมกันกี่เหรียญ** ค่าเริ่มต้น 3 ช่อง
- **อัตราเงินต่อไม้** ถ้าตั้ง 95% ไม้แรกจะกินเงินเกือบหมด  
  อยากถือ 3 เหรียญพร้อมกัน ให้ตั้งประมาณ **30%** ต่อไม้

### มีเหรียญแต่ไม่รู้ราคาจับคู่

ถ้าซื้อแล้วเหรียญเข้าพอร์ต แต่ดึงราคา fill จากตลาดไม่ได้ บอทจะ **ถือต่อทันทีด้วยต้นทุนประมาณ** (offer ตอนซื้อ หรือราคาตลาด) แล้วดูแล trailing / stop loss ตามปกติ

ไม่ต้องรอปลดจากหน้าเว็บ — กันพลาดตอนเหรียญวิ่งขณะที่คุณไม่ได้อยู่หน้าจอ

หน้าเว็บจะขึ้นว่า **ต้นทุนประมาณ** เพราะกำไร/ขาดทุนนับจากราคานี้ ไม่ใช่ fill จริง

HALTED เหลือแค่ตอนที่ยังดึงราคาตลาดไม่ได้เลย รอบถัดไปบอทจะถือต่อเองเมื่อมีราคา

### ตัดขาดทุนแล้วไม่ซื้อคืน

หลังโดน stop loss บอทจะ **หยุดเฝ้าเหรียญนั้น** ไม่ซื้อคืนเอง

ที่การ์ดเหรียญบนหน้าเว็บมีปุ่ม:

- **หยุดเฝ้า** — ไม่เปิดไม้ซื้อเหรียญนี้ (ยังอยู่ในรายการ ไม้ที่ถืออยู่ยังถูกดูแล)
- **เฝ้าต่อ** — ให้บอทซื้อได้อีกเมื่อเข้าเกณฑ์

คุณกดเองว่าจะหยุดหรือเฝ้าต่อ

### แจ้งเตือนมือถือ (Telegram)

บน Render ตั้งค่า:

- `TELEGRAM_BOT_TOKEN` — token จาก [@BotFather](https://t.me/BotFather)
- `TELEGRAM_CHAT_ID` — chat id ของคุณ

วิธีหา chat id: สร้างบอท แล้วส่งข้อความหาบอท จากนั้นเปิด  
`https://api.telegram.org/bot<TOKEN>/getUpdates` ดูเลข `chat.id`

บอทจะส่งเมื่อ ซื้อ, ขาย, ตัดขาดทุน/หยุดเฝ้า, เฝ้าต่อ, และเมื่อ circuit breaker ทำงาน  
ถ้ายังไม่ใส่ค่าทั้งสอง บอทเทรดตามปกติ ไม่พัง

## Firebase สองฐาน

ฐานหลักเก็บแค่สถานะเทรดและการตั้งค่า ฐานที่สองเก็บ bid/offer กับประวัติราคา (เขียนบ่อย)

บน Render ตั้งค่า:

- `FIREBASE_DATABASE_URL` — ฐานหลัก (ของเดิม)
- `FIREBASE_DATABASE_URL_2` — ฐานที่สอง สำหรับตลาด
- `FIREBASE_CREDENTIALS_2` — ถ้าฐานที่สองเป็นคนละโปรเจกต์ ใส่ไฟล์ JSON ที่ `/etc/secrets/firebase2.json`

ถ้ายังไม่ใส่ `FIREBASE_DATABASE_URL_2` บอทจะลง bid/offer ที่ฐานหลักไปก่อน ไม่พัง

หมายเหตุ: แผน Spark ฟรีจำกัด **1 database ต่อโปรเจกต์** ถ้าจะแยกฐานในโปรเจกต์เดียวกันต้องใช้ Blaze หรือสร้างโปรเจกต์ Firebase อีกอัน
