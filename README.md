# Sentinel

บอทเทรด InnovestX แบบ **ซื้อตอนย่อ** — เห็นราคาขึ้นแล้วไม่ไล่ตาม จำยอดไว้ รอย่อ แล้วค่อยเข้าซื้อ

## สูตรเข้าซื้อ (v8)

ตัดเกณฑ์ 1 ชม. / 2 ชม. / 3 ชม. ทิ้งแล้ว ไม่ต้องรอสะสมประวัติ 2 ชั่วโมง

1. ราคาขึ้นจากจุดต่ำอย่างน้อย **0.8%** → บอท**จำยอด**ไว้ ยังไม่ซื้อ
2. ถ้าราคาทำยอดใหม่ → เลื่อนยอดที่จำไว้ (ยังไม่ไล่ซื้อ)
3. ย่อจากยอดที่จำ **0.5–1.5%** → รอเด้งเล็กน้อย
4. เด้งจากจุดต่ำของย่ออย่างน้อย **0.08%** → เข้าซื้อ
5. ย่อลึกเกิน 1.5% หรือหลุดจุดเริ่มพุ่ง → ล้างยอด เริ่มใหม่

ยอดที่จำไว้เก็บบน Firebase ต่อเหรียญ ปิดบอทแล้วยังจำได้

## เฝ้าหลายเหรียญ

เพิ่ม/ลบเหรียญจากหน้าเว็บของบอทได้เลย

1. เปิดหน้าแดชบอร์ด
2. พิมพ์คู่เหรียญ เช่น `ETHTHB` แล้วบันทึกรายการเหรียญ
3. บอทดูทุกเหรียญในรายการด้วยสูตรย่อจากยอดเดียวกัน
4. เข้าซื้อตัวที่ย่อแล้วเด้ง เมื่อยังมีช่องว่าง
5. ขายไม้เก่าแล้ว จะไปมองหาเหรียญถัดไปที่คุณเพิ่มไว้ทันที

### ตั้งค่านิดเดียวให้ถือหลายเหรียญได้จริง

- **ถือได้พร้อมกันกี่เหรียญ** ค่าเริ่มต้น 3 ช่อง
- **อัตราเงินต่อไม้** ระบบแบ่งเงินว่างตามจำนวนช่องว่างให้อัตโนมัติแล้ว ค่านี้คือ % ของเงินที่แบ่งให้ไม้นี้

ของเดิมยังอยู่ครบ: trailing stop, stop loss, ตัดขาดทุนแล้วหยุดเฝ้า, circuit breaker, รหัสผ่านหน้าเว็บ
